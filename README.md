# Tinder Car

Site statique, sans build ni serveur.
1. GitHub Pages: Settings > Pages > Deploy from a branch (racine du dépôt).
2. iPhone: ouvrir le site dans Safari > Partager > Sur l'écran d'accueil.
3. Ajouter à l'écran d'accueil avant de commencer (iOS sépare le stockage de Safari et de l'app installée).
4. À chaque changement, incrémenter `VERSION` dans `sw.js` pour renouveler le cache hors ligne.
